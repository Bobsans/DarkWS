# DarkWS documentation site

Docusaurus site published to GitHub Pages by `.github/workflows/docs.yml`.

```bash
npm ci
npm run api:dotnet   # .NET API reference from XML docs (needs pwsh and the .NET SDK)
npm start            # English dev server
npm run start:ru     # Russian dev server (one locale at a time)
npm run build        # both locales into build/
```

The TypeScript API reference is generated by `docusaurus-plugin-typedoc` on every
start/build. Both references land in `docs/api/` and are not committed.

## Translations

English pages live in `docs/`. Russian pages mirror them under
`i18n/ru/docusaurus-plugin-content-docs/current/` with the same file names; a page
without a translation falls back to English. The API reference is not translated.
Sidebar category labels are translated in `i18n/ru/docusaurus-plugin-content-docs/current.json`.

## Versions

`docs/` is always the upcoming release. Before starting the next major version,
snapshot the current one with both API references generated:

```bash
npm run api:dotnet
npm run docusaurus docs:version 5.x
```

This copies `docs/` into `versioned_docs/version-5.x/` and the Russian pages into
`i18n/ru/docusaurus-plugin-content-docs/version-5.x/`. Commit both. Then
set the label of `current` in `docusaurus.config.ts` to the new major. Version only
majors and keep a few, since every version is a full copy per locale.
